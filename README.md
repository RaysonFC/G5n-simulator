# ZOOM G5n · Patch Lab

Interface estilo hardware da G5n + patches para **Strato Seven SGT-207 NT** (single-coil).

## Destaques
- Overview + 4 Unit Displays + Footswitches + Pedal
- Até 9 efeitos, localStorage, busca de efeitos
- Banco de patches em **carrossel horizontal** (deslize)
- Layout responsivo até 360px (2 colunas nos cards)

## Dica para single-coil
- Comp ou ZNR no início da cadeia
- Drive externo antes da G5n (se usar)
- Delay/Reverb dentro da G5n
- Twin Reverb (FD TWNR) funciona muito bem com Strat

Abra o `index.html` no navegador.  
Patches salvam no localStorage.

**Importante:** se não aparecerem os patches novos, limpe o localStorage do site  
(DevTools → Application → Local Storage → Clear) e recarregue.
